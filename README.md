# فروشگاه محصولات خانگی نارگل

اپلیکیشن فروشگاهی نارگل برای اندروید و آیفون (یک کد مشترک با Flutter) به‌همراه سرور سفارش و پرداخت.

## ساختار پروژه

| پوشه | توضیح |
|---|---|
| `app/` | اپلیکیشن (Flutter) — اندروید، آیفون و وب |
| `server/` | سرور (Node.js) — محصولات، سفارش‌ها، پنل مدیریت، پرداخت زرین‌پال |
| `tools/` | اسکریپت ساخت کاتالوگ از روی عکس‌های محصولات |

## امکانات

**مشتری:** ۱۶۷ محصول در ۱۲ دسته، جستجو، انتخاب وزن/اندازه زیر هر محصول، سبد خرید،
ارسال با پیک یا تحویل در شعبه، پرداخت آنلاین زرین‌پال، پیگیری سفارش، اطلاعات شعبه‌ها و مجوزها.

**مدیر (از داخل همین اپ، صفحه «درباره ما» ← «ورود مدیر فروشگاه»):**
افزودن/ویرایش/حذف محصول، تغییر عکس، تعریف هر تعداد گزینه وزن و قیمت برای هر محصول،
ناموجود کردن محصول یا یک گزینه، مدیریت دسته‌ها، هزینه ارسال، حداقل سفارش، شعبه‌ها،
مشاهده سفارش‌ها و تغییر وضعیت آن‌ها، تغییر رمز.

## حالت نمایشی و حالت واقعی

- اگر اپ **بدون** `API_BASE` ساخته شود، در **حالت نمایشی** اجرا می‌شود: همه چیز روی خود گوشی ذخیره می‌شود و پرداخت آزمایشی است. رمز مدیر: `1234`.
- برای فروش واقعی، سرور را راه‌اندازی کنید و اپ را با آدرس سرور بسازید:
  ```bash
  flutter build apk --release --dart-define=API_BASE=https://api.nargol.ir
  ```

## راه‌اندازی سرور

نیاز: Node.js نسخه ۲۲.۱۳ یا بالاتر.

```bash
cd server
npm install
ADMIN_PASSWORD=رمز-قوی PUBLIC_URL=https://api.nargol.ir ZARINPAL_MERCHANT=مرچنت-کد node server.js
```

- `ZARINPAL_MERCHANT` خالی باشد ← درگاه آزمایشی (sandbox) زرین‌پال.
- اطلاعات در `server/data/nargol.db` ذخیره می‌شود؛ از این فایل و پوشه `server/public/images` نسخه پشتیبان بگیرید.
- سرور باید پشت HTTPS باشد (مثلاً با Nginx و گواهی Let's Encrypt).

## ساخت اپ

- **خودکار:** با هر push به شاخه `main`، فایل APK در بخش Actions گیت‌هاب ساخته می‌شود.
  برای آیفون، متغیر `BUILD_IOS=true` را در تنظیمات Actions تعریف کنید.
- **دستی:**
  ```bash
  cd app
  flutter pub get
  flutter build apk --release
  ```

## به‌روزرسانی عکس‌ها و کاتالوگ اولیه

```bash
python3 tools/build_catalog.py <پوشه-عکس‌ها> app/assets/products app/assets/data/catalog.json
```
